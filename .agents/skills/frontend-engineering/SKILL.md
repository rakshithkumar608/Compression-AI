# Frontend Engineering Skill

## Principles
1. Build a clean, accessible, developer-focused interface using Next.js (App Router or Pages Router with TypeScript) and Tailwind CSS.
2. Maintain strict separation between presentation components and API integration layers.
3. Every screen must handle five distinct states: Empty, Loading, Active/Running, Success, and Error.
4. Clearly label illustrative preview data, templates, or demo values. Never let the user confuse illustrative figures with real experiment benchmarks.
5. Provide accessible contrast, clear typography, responsive layouts, and non-blocking notification toasts for background tasks.
