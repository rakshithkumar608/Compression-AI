# Project Planning Skill

## Principles
1. Read the blueprint (`docs/EcoCompress_AI_Complete_MVP_Blueprint.docx`) and inspect existing code before proposing changes.
2. Verify hardware limits and free disk space before any file generation or tool installations.
3. Work one milestone at a time; never advance to the next milestone without explicit user approval.
4. If a proposed step risks storage exhaustion or breaks compatibility, halt immediately and report the blocker.
